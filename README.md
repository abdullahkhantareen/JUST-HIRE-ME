Recruit AI (OrchestraHR) :

Recruit AI (OrchestraHR) is an enterprise-grade recruitment and candidate tracking platform built using a Node.js and Express backend architecture paired with two standalone web portals. The application decouples applicant interactions from administrative workflows, allowing recruitment teams to manage hiring pipelines while offering job seekers a streamlined application experience.

 System Architecture & Services :

The repository contains three primary application modules:

Backend API (/backend): A Node.js Express server listening on http://localhost:4000 that handles core business logic, database operations, file storage, and data serving.

Internal HR Console (/frontend-internal): A web application listening on http://localhost:3001 built for recruiters and HR administrators to evaluate candidates, post listings, and track application pipelines.

Candidate Portal (/frontend-candidate): A public-facing web interface listening on http://localhost:3000 where job seekers can view open roles and submit applications.
